# Bethesda Ministries JPT

Welcome to the official website repository for **Bethesda Ministries JPT (Jaggayyapet)** — *Worship, Word & Witness*.

---

## 🕊️ About Bethesda Ministries JPT

Bethesda Ministries is a Christ-centered ministry located in Jaggayyapet, dedicated to spreading the Gospel, empowering believers through Biblical teachings, heartfelt worship, and active community outreach.

- **Founders & Pastors:** Pastor Ch. Yacob Garu & Ministry Leadership
- **Location:** Jaggayyapet, Krishna District, Andhra Pradesh, India
- **Motto:** *Worship, Word & Witness*
- **Scripture Anchor:** *"Thy word is a lamp unto my feet, and a light unto my path."* — Psalm 119:105

---

## ✨ Features of the Website

- **Modern & Responsive Design:** Fully responsive layout built with clean HTML5, modern CSS3 (Flexbox/Grid), and vanilla JavaScript.
- **Bilingual Support (English & Telugu):** One-click language switch between English and Telugu across all sections.
- **Continuous Auto-Scrolling Messages Carousel:** Smooth 60fps ticker with touch/pointer hover pausing and navigation arrows.
- **In-Page Compact YouTube Video Modal:** Stream church messages and worship videos directly inside the website without external tab redirection.
- **Monthly Magazine Archive & Interactive Catalogue:**
  - Fast-browsing card carousel for recent 2026 magazine issues.
  - Multi-faceted filter system (Discipline, Academic Level, Format, Year) with live search and dynamic result counter.
- **What We Believe:** Interactive doctrine cards highlighting core biblical foundations with dynamic hover depth.
- **Bethesda Bible Institute:** Course overview cards covering Foundations of Faith, Old & New Testament surveys, Pastoral Ministry, and Evangelism.
- **Faculty & Preachers Showcase:** Highlighting ministry leaders and church faculty.
- **Programs & Weekly Schedule:** Sunday Worship, Wednesday Midweek Prayer, and Friday Fasting Prayer schedules.
- **Interactive Contact & Prayer Request Form:** Integrated modal for prayer requests and direct outreach.

## 🚀 Getting Started

### Local Setup
Simply clone the repository and open `index.html` or `JPT.html` in any modern web browser:

```bash
git clone https://github.com/shafiulla2002/Bethesda-Ministries-JPT.git
cd Bethesda-Ministries-JPT
# Open in browser:
# On Windows:
start index.html
# On macOS:
open index.html
# On Linux:
xdg-open index.html
```

Or run using VS Code Live Server or Python HTTP server:
```bash
python -m http.server 5500
```
Then visit `http://localhost:5500`.

## 🌐 GitHub Pages Deployment

To view this site live on GitHub Pages:
1. Navigate to **Settings** > **Pages** in this GitHub repository.
2. Under **Build and deployment**, select `Deploy from a branch`.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**. The website will be live at `https://shafiulla2002.github.io/Bethesda-Ministries-JPT/`.
